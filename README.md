## 🚀 Cómo Iniciar en Cualquier Computadora:

### En Mac / Linux:
* Haz doble clic sobre **`iniciar_mac_linux.command`**.
* *(O abre la terminal y ejecuta: `python3 -m http.server 8080`)*.

### En Windows:
* Haz doble clic sobre **`iniciar_windows.bat`**.

Se abrirá tu navegador web automáticamente en **`http://localhost:8080`**.
